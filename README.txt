Viktigt:
PWA-funktioner som installation och offline-cache kräver att appen öppnas via HTTPS eller localhost.
Att öppna index.html direkt från iPhone-filer/ChatGPT förhandsvisning räcker inte.

iPhone:
1. Publicera mappen på en vanlig HTTPS-webbserver.
2. Öppna webbadressen i Safari.
3. Tryck Dela.
4. Välj Lägg till på hemskärmen.
5. Starta appen från hemskärmen.
